# Reactive workspace engine - check inventory

Deliverable (b) of section 8 of `docs/todo/graymoon-reactive-architecture-implementation.md` (workspace root repository). One row per check. The ledger is `progress.md` beside this file.

## How to read a row

- **ID** is stable. `R` = Feature removal (appendix A.1.1 step number), `F` = Feature create / repair / roll back / reconcile (A.2), `W` = Workspace operations (A.3), `B` = background checks and freshness (A.4), `X` = peripheral mutation boundaries (added by package X1).
- **Code path** names a method; the method is the anchor, not a line number.
- **Status** is `untraced` (not read yet in the current code), `traced` (path, trigger, invariant and current work confirmed in the current code), then the decision: `retained`, `replaced`, `narrowed` (a guard that now refuses more, or work scoped down), `extended` (the check stays and does more), `reduced` (the same result with less work), `background` (moved behind the end of the operation, with what waits for it), `deferred`, `eliminated` or `blocked` (with the exact reason). A row moves to a decision only together with the test that proves it. A moved check is not counted as removed.
- **Current work** counts Worker commands, git processes, remote calls and scans. "est." marks an estimate; everything else was read from code or a test.
- **Measured** names a test that counts, or a row of the VDI table in section 2.3 of the plan. Empty means not measured.
- **Pkg** is the work package that owns the decision.

| Fact | Where Create takes it from | What a Feature's lifetime or removal can make stale | Kept current by |

| `GitVersion` | Not copied: the Feature starts pending | - | Feature's own first probe |
| Remote branch rows, tag rows | Shared rows, not copied | Pruned or new remote branches | Fetch-only step (pruning included) |
